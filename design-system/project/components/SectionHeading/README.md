# SectionHeading
The title block that opens every section: eyebrow, title, a short gold rule and an optional lead paragraph.

**Consumer provides:** eyebrow text (optional), the section title as `<h2>` (use `<h1>` only for the Projects page title), lead text (optional). Add `mp-heading--center` for centred sections; wrap in `.mp-dark` on `surface-dark`.

**Rules:** title in `heading-2` (`ink`), eyebrow in `eyebrow` (`brand-maroon`), lead in `body-lg` (`ink-muted`), rule in `brand-gold` (decorative, so contrast-exempt). Use the approved copy from the README; never invent claims or numbers in the lead.
