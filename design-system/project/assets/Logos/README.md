# Logos

Client-supplied Memora Plus logos (`VID/logos/logo/`), trimmed of transparent margins only — artwork, colours and proportions untouched.

- `memora-plus-logo-01-trimmed.webp` — maroon mark, gold wordmark. Default on `surface-white` / `surface-cream`; header (56px high).
- `memora-plus-logo-02-trimmed.webp` — gold mark, maroon wordmark. Footer on `surface-dark` (72px high), approved as-is.
- `memora-plus-icon-01.webp` — maroon mark only. Compact header (40px), favicon, social image.
- `memora-plus-icon-02.webp` — gold mark only. Mark on `surface-dark`.

Raster WebP with transparency (source 3750×3750). PNG copies sit beside them in the project folder. Request an SVG from the client for the sharpest result.
