# Memora Plus — الموقع (Next.js، تصدير ثابت)

موقع من صفحتين — **الرئيسية** و**المشاريع** — بثلاث لغات: العربية (افتراضية، `/ar/`)، الإنجليزية (`/en/`)، التركية (`/tr/`). مبني على نظام التصميم المعتمد في `../design-system/`.

## التشغيل
```bash
npm install
npm run dev        # للتطوير: http://localhost:3000/ar/
npm run build      # يولّد الموقع الثابت في مجلد out/
npm start          # يعرض مجلد out/ محلياً
```
مجلد `out/` جاهز للرفع على أي استضافة ملفات ثابتة (Netlify، Vercel، Cloudflare Pages، أو أي استضافة عادية). افتح الموقع عبر خادم وليس بالنقر المزدوج على الملفات.

## أين أعدّل؟
| ماذا | أين |
|---|---|
| نصوص الشركة (معتمدة) والترجمات | `src/content/site.ts` |
| بيانات المشاريع (تجريبية الآن) | `src/content/projects.ts` |
| صور المشاريع | ضعها في `public/projects/` واكتب مسارها في حقل `image` |
| فيديو تعريفي | `CONTACT.introVideoId` في `src/content/site.ts` |
| Google Analytics / Meta Pixel | انسخ `.env.example` إلى `.env.local` واملأ المعرّفات (تعمل بعد موافقة الزائر فقط) |
| رابط الموقع النهائي | `NEXT_PUBLIC_SITE_URL` (للروابط الأساسية وhreflang) |

## ما زال ناقصاً من العميل
بيانات المشاريع وصورها الحقيقية · الفيديو التعريفي · البريد والعنوان ورابط الخريطة · مراجعة الترجمتين الإنجليزية والتركية · سياسة الخصوصية (يُضاف رابطها لشريط ملفات الارتباط) · معرّفات التتبع.
